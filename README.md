# Livdub Personal

تطبيق أندرويد شخصي (مجاني، بلا إعلانات، بلا سيرفر خارجي) بيعمل **دبلجة/ترجمة صوتية فورية** بالاعتماد على
[Gemini Live API - Live Translate](https://ai.google.dev/gemini-api/docs/live-api/live-translate)، بنفس فكرة إضافة `livdub`.

الصوت بيتصور محلياً على تلفونك، ينبعت مباشرة من تلفونك لـ Google (Gemini) بمفتاح الـ API تبعك، وبيرجع صوت مترجم تسمعه بسماعتك. ما في أي سيرفر وسيط تبعي أنا.

## شو بيعمل التطبيق

- **وضع المايك**: بتحكي، وبيطلعلك صوت مترجم للغة يلي اخترتها (متل مترجم فوري).
- **وضع صوت النظام**: بياخد صوت أي تطبيق عم يشتغل عالتلفون (يوتيوب مثلاً) عبر `AudioPlaybackCaptureConfiguration`
  ويبعته للترجمة، وبيشغللك الصوت المترجم.

## ⚠️ قيود مهمة لازم تعرفها

1. **وضع صوت النظام ما بيكتم الصوت الأصلي تلقائياً** — أندرويد ما بيسمح لتطبيق عادي (بدون روت) يكتم صوت تطبيق
   تاني وهو عم يسجله بنفس الوقت. يعني رح تسمع الصوت الأصلي + الصوت المدبلج مع بعض. أفضل حل عملي: نزّل صوت
   وسائط التلفون (Media Volume) شوي وخلي التطبيق يشتغل بسماعة/سماعات رأس، أو جرّب هيك التطبيق أساساً كمترجم
   حي (وضع المايك) لأنه هو الاستخدام الأوثق.
2. **يلزم موافقة "تسجيل الشاشة"** — نظام أندرويد بيربط صلاحية التقاط صوت التطبيقات (`MediaProjection`) بنفس
   صلاحية تسجيل الشاشة حتى لو إحنا بس عم ناخد الصوت. هيك بيطلب منك النظام تأكيد كل مرة تبلش فيها هالوضع.
   التطبيق ما بيسجل أو يخزن أي فيديو أو صوت — بس بيمرره للترجمة مباشرة.
3. **نموذج تجريبي (preview)** — `gemini-3.5-live-translate-preview` ممكن يتغيّر أو يصير إله حدود استخدام/تسعير
   من طرف Google؛ تأكد من صفحة [Pricing](https://ai.google.dev/gemini-api/docs/pricing) قبل استخدام مكثف.
4. المفتاح (API key) بينحفظ محلياً بس على تلفونك (SharedPreferences)، ما بينبعت لأي سيرفر غيري أنا.

## كيف تجيب مفتاح Gemini API (مجاني)

1. افتح <https://aistudio.google.com/apikey>
2. سجل دخول بحساب Google.
3. اعمل "Create API key" وانسخه.
4. الصقه بالتطبيق بخانة "Gemini API Key".

في حصة مجانية شهرية محدودة من Google؛ إذا تجاوزتها لازم تفعّل الفوترة على حساب Google Cloud تبعك.

## كيف تبني الـ APK عبر GitHub Actions

1. اعمل مستودع (repo) جديد على GitHub، وارفع كل ملفات هاد المشروع (رفع المجلد كامل زي ما هو).
2. أول ما ترفع على فرع `main`، الـ workflow المرفق بمجلد `.github/workflows/build.yml` رح يشتغل تلقائياً:
   - بينزّل JDK 17 + Android SDK.
   - بيبني نسخة Debug من الـ APK.
   - بيرفعها كـ "Artifact" اسمه `livdub-personal-debug-apk`.
3. من تبويب **Actions** بمستودعك، افتح آخر تشغيل ناجح (✅)، وبآخر الصفحة تحت "Artifacts" حمّل الملف المضغوط،
   وجواه رح تلاقي ملف `.apk` نزّله عتلفونك وثبته (لازم تفعّل "تثبيت من مصادر غير معروفة" لمرة وحدة).

> إذا حبيت تبني محلياً بدل GitHub Actions: افتح المشروع بـ Android Studio (Giraffe أو أحدث)، خليه يعمل Sync،
> وبعدين Run على تلفونك مباشرة.

## البنية

```
app/
  src/main/java/com/livdub/personal/
    MainActivity.kt        # الواجهة: مفتاح API + لغة الهدف + مصدر الصوت + زر بدء/إيقاف
    DubbingService.kt       # خدمة أمامية: تسجيل الصوت + تشغيل الصوت المترجم
    GeminiLiveClient.kt     # اتصال WebSocket مع Gemini Live Translate
    Prefs.kt                 # تخزين محلي بسيط
  src/main/res/             # الواجهات والنصوص والأيقونة
.github/workflows/build.yml # بناء تلقائي للـ APK
```

## أفكار لتطوير لاحق (اختياري)

- خلط صوت المايك + صوت النظام سوا بنفس الجلسة.
- عرض الترجمة النصية (subtitles) بالاستفادة من `inputAudioTranscription` / `outputAudioTranscription`
  يلي أصلاً التطبيق عم يفعّلهم بس مش عم يعرضهم بالواجهة.
- حفظ قائمة لغات مفضّلة، أو تبديل اللغة أثناء التشغيل.
